Python String Formatting

Topic 05 · Building Cleaner Output From Your Variables

Learning Objectives

  • Combine strings and variables cleanly using f-strings.
  • Insert values into a string using the .format() method.
  • Control number precision, width, and alignment with format specifiers.
  • Compare f-strings, .format(), and % formatting, and know when to use each.
Getting Started

Why Do We Need String Formatting?

Joining text and variables directly gets messy fast — formatting keeps it clean.

  • The problem: Using + to join strings and numbers requires converting every number with str() first, or Python raises a TypeError.
  • The fix: String formatting lets you drop variables straight into a sentence, no manual conversion needed.

"Hi " + name + "!" needs str(); f"Hi {name}!" just works.

Syntax

f-Strings — The Modern Way

Put an f right before the opening quote, then drop variables inside curly braces.

fstrings_basics.py 
name = "Jerico"
age = 21
print(f"My name is {name} and I am {age} years old.")
# My name is Jerico and I am 21 years old.
Tipf-strings were introduced in Python 3.6 and are now the recommended way to format strings.
Syntax

Expressions Inside f-Strings

You're not limited to plain variables — f-strings can hold any expression, even function calls.

fstring_expressions.py 
name = "jerico"
price = 250
quantity = 3

print(f"Total: {price * quantity}")       # Total: 750
print(f"Name in caps: {name.upper()}")    # Name in caps: JERICO
ExampleAnything that evaluates to a value works inside { } — math, method calls, even function calls.
Syntax

The .format() Method

Curly-brace placeholders get filled in by the values passed to .format().

format_method.py 
name = "Jerico"
age = 21

print("My name is {} and I am {} years old.".format(name, age))
print("My name is {0}. Hi again, {0}!".format(name))
NoteNumbering the braces like {0} lets you reuse or reorder values — plain {} just fills in order.
Legacy Style

Old-Style % Formatting

You'll still see this in older code — %s for strings, %d for integers, %f for floats.

percent_formatting.py 
name = "Jerico"
age = 21
print("My name is %s and I am %d years old." % (name, age))
# My name is Jerico and I am 21 years old.
Important% formatting still works, but f-strings are easier to read and are preferred in new code.
Numbers

Controlling Decimal Precision

Add :.Nf inside the braces to round a float to N decimal places.

precision.py 
pi = 3.14159265
price = 19.9

print(f"Pi rounded: {pi:.2f}")     # Pi rounded: 3.14
print(f"Price: ${price:.2f}")      # Price: $19.90
Tip:.2f always shows exactly 2 digits after the decimal point, even if that means adding a zero.
Numbers

Width & Alignment

A width number pads a value with spaces; <, >, and ^ control alignment.

SpecMeaningResult for 42
{:6}Right-align in a 6-space width (default for numbers)"    42"
{:<6}Left-align in a 6-space width"42    "
{:^6}Center-align in a 6-space width"  42  "
{:06}Pad with zeros instead of spaces"000042"
ExampleCombine width with a fill character, like {:*^10}, to pad with any character you want.
Numbers

Thousands Separators & Percentages

A comma groups digits by thousands; % turns a decimal into a percentage.

separators_percent.py 
population = 1234567
score = 0.842

print(f"Population: {population:,}")   # Population: 1,234,567
print(f"Score: {score:.1%}")           # Score: 84.2%
Note:.1% multiplies by 100, rounds to 1 decimal, and adds the % sign automatically.
Reference

f-string vs .format() vs %

All three produce the same output — here's how the syntax compares.

StyleExampleBest For
f-stringf"{name} is {age}"New code — readable, fast, supports expressions
.format()"{} is {}".format(name, age)Reusing/reordering values, Python < 3.6
% formatting"%s is %d" % (name, age)Reading legacy/older codebases
TipWhen writing new code, reach for f-strings first unless you have a specific reason not to.
Applied Example

Example: Printing a Formatted Receipt

Formatting shines when lining up columns of numbers neatly.

receipt.py 
name1, qty1, price1 = "Pen", 2, 15.5
total1 = qty1 * price1
print(f"{name1:<10}{qty1:>3} x {price1:>6.2f} = {total1:>8.2f}")

name2, qty2, price2 = "Notebook", 1, 45.0
total2 = qty2 * price2
print(f"{name2:<10}{qty2:>3} x {price2:>6.2f} = {total2:>8.2f}")

# Pen         2 x  15.50 =    31.00
# Notebook    1 x  45.00 =    45.00
Example<10 left-aligns the name in a 10-character column, keeping every row lined up.
Recap

Summary — Key Points

Here's everything we covered in this topic, in one glance.

f"{ }" inserts variables and expressions directly into a string.
"{}".format(...) fills placeholders, in order or by number.
% formatting is the older style, still seen in legacy code.
Format specifiers control precision, width, alignment, and separators.

Did You Know?

Fun Facts About String Formatting

A few fun tidbits to impress your friends.

A Handy Debugging Shortcut

Writing f"{value=}" prints both the variable's name and its value, which is great for quick debugging.

% Formatting Predates Python Itself

The % operator borrows its syntax from C's printf, one of the oldest formatting styles in programming.

f-Strings Are the Fastest

Because they're evaluated directly by the interpreter, f-strings typically outperform .format() and % formatting.

Format Specs Work Everywhere

The same :.2f, :,, and alignment codes work in both f-strings and .format() — only the outer syntax differs.
